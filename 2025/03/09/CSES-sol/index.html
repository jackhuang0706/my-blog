Missing Number

Solution

因為 $1+2+…+n=\frac{n(n+1)}{2}$，所以只要用 $\frac{n(n+1)}{2}$ 減去給定的 $n-1$ 個數字之和就可以得到答案。

Code

Repetitions

Solution

用 cnt 記錄目前最長連續且相同字元的長度，然後用一個迴圈跑，每次比較當前的字元跟前一個是不是一樣，如果一樣就 $\text{次數}+1$，否則將 cnt 令為 $1$ 重算。

Code

Increasing Array

Solution

因為高度只能增加不能減少，因此如果遇到 $x_{i+1}<x_i$ 的狀況，只需要把moves的值加上 $|x_i-x_{i+1}|$ 就好。

Trailing Zeros

Solution

因為後綴 $0$ 一定是由一個 $2$ 和一個 $5$ 相乘得來，因此要找的答案是在 $n!$ 中有幾個 $2$ 和幾個 $5$ 可以用來相乘變成一組 $10$，但如果直接從 $1$ 一個一個檢查到 $n$ 會超時，因此必須找到一個更快的方法，可以發現 $2、4、6、8、10、12、14、16…$ 這些數字依序包含了 $1、2、1、3、1、2、1、4…$ 個 $2$，不難發現 $2$ 個倍數至少包含一個 $2$、$4$ 的倍數至少包含兩個 $2$、$8$ 的倍數至少包含三個 $2$…，又在 $n$ 以內的 $2$ 的倍數必有 $\lfloor \frac{n}{2} \rfloor$ 個、$4$ 的倍數必有 $\lfloor \frac{n}{4} \rfloor$ 個…依此類推，所以只要用一個變數 temp 下去跑，每次增加兩倍，這樣可以在 $O(\log n)$ 的時間計算完。例如：令 $S_0=(1,2,1,3,1,2,1,4)$ 把 $2$ 的倍數全部刪掉一個 $2$，可得 $S_1=(0,1,0,2,0,1,0,3)$，再把 $4$ 的倍數刪掉一個 $2$ 可得 $S_2=(0,0,0,1,0,0,0,2)$，再把 $8$ 的倍數刪掉一個 $2$ 可得 $S_3=(0,0,0,0,0,0,0,1)$，最後把 $16$ 的倍數刪掉一個 $2$ 可得 $S_4=(0,0,0,0,0,0,0,0)$。

Coin Piles

Solution

用數學解方程式就好。假設第一種操作為 $x$（左 $1$ 右 $2$）、第二種操作為 $y$（左 $2$ 右 $1$），那方程式可寫為
$$
\begin{cases}
x+2y=a \newline
2x+y=b
\end{cases}
$$
只要判斷 $x,y$ 是不是非整數解就好。
